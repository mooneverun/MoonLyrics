# MoonLyrics · 月光歌词

以柔和、通透的玻璃材质呈现桌面悬浮歌词。

当前版本是 **Windows 同步歌词测试版**：保留已经实际试用确认的玻璃效果，跟随 Windows 版 Apple Music 自动匹配歌词，在玻璃框内居中滚动、上下渐隐。

## 已有功能

- 自动跟随 Apple Music，显示歌曲、歌手、专辑、播放状态、当前进度与总时长。
- 暂停时冻结进度，恢复、切歌及拖动进度后重新校准；不会跟随浏览器等其他播放器。
- 媒体读取在后台线程运行，系统事件与半秒检查配合本地时钟平滑显示进度。
- 从酷狗、LRCLIB、网易云音乐与 QQ 音乐获取带时间戳的歌词，联合核对曲名、歌手与时长，拒绝同名翻唱及不同版本。四个来源自动兜底，无需额外登录；只返回纯文本的结果不会作为同步歌词使用。
- 设置中的“歌词源顺序”按从左到右自动尝试，默认酷狗 → LRCLIB → 网易云 → QQ 音乐。四个位置均可调整，选择已有来源时交换位置；更改后立即重新匹配当前歌曲，仍会自动尝试后续来源。顺序随设置保存，内存缓存按来源顺序区分，方便对比不同来源的歌词和同步效果。
- 合唱署名允许顺序、逗号、`&` 与 `feat.` 等分隔方式不同，也支持合作歌手由曲名移到歌手列表，仍须核对完整歌手名单；精确搜索无结果时按曲名补查，再在本地验证歌手和时长。
- 四个来源均补查不带合作署名的基础曲名；网易云与 QQ 在组合查询后还会只按曲名补查，并用完整署名、歌手编号资料、版本及时长核对候选。兼容 `feat.Guest`、`ft.`、带嵌套括号的合作名与括号中的 `with`，合作署名移除后仍保留 Live 等版本标记。
- 网易云与 QQ 的候选先核对曲名、版本及时长，再按来源歌手编号匿名查询资料，用结构化姓名、译名和别名核对中、英、韩合作署名。Apple 同一曲目不同地区的主唱和合作署名可组合核对，每位歌手仍须一一对应；缺人、多出歌手、不同编号同名或资料编号不符时拒绝。已核实资料在进程内按来源及歌手编号复用，不按单首歌维护别名表；查询失败不缓存，每轮最多追加 6 次歌手资料请求，并遵守原有总超时和切歌取消。
- 中文歌名支持简繁体归一；土耳其区的英文、繁体名称可通过 Apple 同一曲目编号查询港台、韩国区名称。韩文与英文曲名、艺名可组合核对；双语曲名的两部分均须对应已核实的名称，不靠发音或模糊相似度猜测。默认曲目地区为土耳其，可在设置中调整。
- 跨地区名称分别查询，单个地区失败不会跳过其他地区；空结果或失败的名称查询不留作缓存。单个歌词候选下载失败后继续检查后续候选。
- 中文名称不会提前阻止韩国区名称查询；后续地区查询超时也保留此前按同一曲目编号核实的名称，让歌词源继续兜底。地区信息补齐了合作名单时，以已核实的完整名单为准，仍拒绝缺少合作歌手的结果。歌词搜索接口临时失败或漏曲时，也可继续按同歌手、同专辑回查。
- 只返回原名而没有新别名的歌手资料仅在本轮复用，下轮自动重试会重新查询；缓存中的歌手编号出现新名称时重新核对资料。手动重新匹配和自动重试均刷新曲目名称及歌手别名缓存。
- 同步歌词至少须有两个处于歌曲时长内的有效时间点；单条占位提示、纯文本、异常偏移或超出歌曲范围的结果不会阻止后续候选及其他来源。歌词原始时间戳保留，显示时再应用统一校准。
- Apple 歌曲搜索漏掉当前录音时，通过同歌手、同专辑的公开曲目找到专辑编号，最多回查两张专辑；重新核对完整曲名、歌手和时长后，再用找到的同一曲目编号查询地区名称。不会把搜索返回的伴奏版当作人声版，也不需要 Apple 登录。
- 来源的合作署名带有 `of 某组合` 附注，或在曲名和歌手列表中重复使用不同语言时，通过已核实的歌手资料对应到同一人，避免重复计数；仍拒绝未知或多出的合作歌手，主唱名称中的 `of` 不做删减。多人被错误合并为单一歌手条目的含混结果仍会跳过，由后续来源兜底。
- 歌词正文统一显示简体中文，保留英文与原始时间戳；显示字形不受 Apple Music 账号地区影响。
- 普通搜索失败时，自动查询曲库目录，识别“中文姓名＋英文艺名”等写法差异，例如“連麻 / 连麻Swimming”，无需逐个补入歌手表。只有目录中候选艺名与歌手编号唯一、中文姓名一致、曲名吻合且时长相差不超过 2 秒，才接受自动发现的候选；多人合作、翻唱标签或有歧义的身份会拒绝。完全不同写法的跨地区名称优先依靠 Apple 同一曲目编号核对，仍不能核实的别名可能漏配。
- 中间一行清晰显示，相邻歌词淡化；歌词始终裁切在背景框内。换行提前约半秒缓入，在歌词时间点到位；字号与亮度连续过渡。
- 平滑吸收系统进度的小幅校正，避免在换行点反复上下抖动；暂停保持位置，明显的进度跳转会立即重新定位。
- 所有歌词源统一以“提前 1 秒”为默认基准，可点击“提前／延后 0.1 秒”微调，最终可提前或延后最多 3 秒。已有手动校准值保留，升级不会额外再叠加 1 秒；旧版的默认零校准升级为提前 1 秒。重置回到提前 1 秒，显式调回原始时序也能保存，不改变歌曲播放进度。
- 首次匹配失败后，分别等待 2 秒、6 秒自动重试，最多额外尝试两次；界面会显示重试状态。切歌、手动重新匹配或退出会取消旧重试；支持内存缓存。最终仍未找到时显示歌曲与时间。
- 自动匹配先等待 600 ms，让切歌信息稳定；忽略同一歌曲不超过 1 秒的时长波动，时长短暂缺失时沿用该歌曲已知时长，避免反复取消查询。新歌曲信息不完整时等待补全，旧歌曲结果不会覆盖当前歌曲。
- 每轮查询设置 20 秒总预算，并为各来源及名称查询分配时间，避免慢来源耗尽后备来源的机会；服务异常与完整搜索后无结果分别提示。
- 固定使用“凝润”磨砂玻璃，采用均匀高斯模糊，不再选择风格；旧版的清透、柔光设置自动迁移到凝润，透明度和尺寸仍可调。
- 设置界面使用月光图标、深蓝凝润玻璃面板与统一控件；内容可滚动、窗口可拖动缩放。Windows 11 22621 及以上尝试系统 Desktop Acrylic 背景，其他系统使用相同配色的不透明底色以保持可读。
- “背景透明度 1–10”同时调节歌词条和设置面板，并平滑过渡；设置面板保留系统磨砂与清晰的文字、按钮。系统不支持玻璃背景时，设置页保持不透明以便阅读。
- 设置窗口可收起到系统托盘，歌词继续显示；点击托盘月光图标或右键“打开设置”恢复，右键可退出。关闭按钮仍退出程序；托盘不可用时正常最小化到任务栏。
- 背景透明度 1–10，沿用原型 90–100% 的范围，支持约 240 ms 平滑过渡。
- 拖动悬浮条、锁定与鼠标穿透，调节背景框宽度与高度。
- 真实桌面局部取样、边缘折射与高光；悬浮条自身排除在取样之外。
- 15 / 30 / 60 FPS 刷新上限、暂停刷新和 CPU / 内存 / 绘制耗时显示。
- 桌面图像在本机处理，不保存、不上传。
- 歌词匹配会向 Apple 曲目服务、酷狗、LRCLIB、网易云音乐和 QQ 音乐查询歌名、歌手及时长，不上传桌面图像或账号凭据。Apple 仅用于公开曲目名称核对，不获取其订阅歌词。

## 运行

使用 64 位 Windows 10（2004 或更新版本）/ Windows 11，显卡驱动需要支持 OpenGL 3.3。开发环境使用 Python 3.12。播放信息来自本机 Apple Music 的 Windows 媒体会话，MoonLyrics 不需要额外的 Apple ID 登录。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

打开 Windows 版 Apple Music 并播放歌曲，等待歌词匹配完成。未检测到会话时显示等待状态，Apple Music 启动后会自动连接。匹配需要网络，第三方歌词库不保证覆盖所有歌曲、地区和版本；歌词时间戳的准确性也取决于来源。

网易云音乐与 QQ 音乐使用可匿名访问的网页接口，没有官方稳定性保证，可能受到网络、地区或接口变更的影响。遇到登录要求、访问限制或服务错误时跳过该来源，不索取账号、Cookie 或验证码，继续尝试其他来源。

设置和日志位于 `%LOCALAPPDATA%\MoonLyrics\`。首次启动可读取旧玻璃原型的设置，之后保存到 MoonLyrics 自己的目录。

匹配日志记录来源请求异常、候选数量、已核实的公开歌手编号与别名数量及重试结果，便于区分临时服务异常和没有合适歌词，不记录歌词正文或歌手简介。歌手资料缺少对应别名或服务受限时仍可能漏配，不从简介或发音相似度猜测身份。

## 检查与打包

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe main.py --self-test
.\.venv\Scripts\python.exe main.py --media-probe
.\.venv\Scripts\python.exe main.py --lyrics-probe "遠走高飛" "Sam Lee" 269.944
.\build.ps1 -Python .\.venv\Scripts\python.exe
```

打包结果为 `dist\MoonLyrics.exe`，使用者无需安装 Python 或 PyQt6。渲染自检会短暂显示独立的测试图案窗口，检查细条纹模糊、背景取样、透明度动画、歌词裁切与滚动，以及实际绘制性能；需要交互式 Windows 桌面，不能用无界面测试替代。

`--media-probe` 会只读检查约 5 秒的真实媒体会话，不控制 Apple Music 播放。可增加 `--report <路径>` 保存诊断结果，其中包含当前歌曲信息；分享前请自行检查。

`--lyrics-probe` 检查指定歌曲的在线匹配，仅输出来源、匹配曲目及时间戳数量，不输出完整歌词。也支持 `--report <路径>`。

## 开发基础

- `moonlyrics/styles.py`：与平台无关的玻璃风格、透明度映射与设置校验。
- `moonlyrics/playback.py`：与平台无关的播放快照、进度时钟、歌词时钟校正与曲目信息处理。
- `moonlyrics/windows_media.py`：Windows 媒体会话读取、事件订阅与后台线程。
- `moonlyrics/lyrics.py`：与平台无关的同步歌词解析、曲目验证与跨地区名称匹配。
- `moonlyrics/lyrics_worker.py`：后台搜索、切歌取消与最新结果分发。
- `moonlyrics/lyric_paint.py`：Qt 歌词文字层、居中排布、裁切与渐隐。
- `moonlyrics/windows.py`：当前 Windows 桌面取样、渲染、悬浮窗口和设置界面。
- `main.py`：启动入口。

macOS 原生版本尚未实现，后续保留独立的平台实现，共用歌词、播放时钟与设置规则。
